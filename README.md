# FirstStop-M

Zero-budget Flutter car wash + coffee shop management app.

## Planned platforms
- Android and Flutter Web
- Supabase free-tier backend
- English and Amharic user interface

## Development
Work-in-progress features are proposed via pull requests. The MVP will include role-based access, car wash tickets, coffee POS, inventory and an owner dashboard.

No live payment processing is enabled. Financial and operational features require testing before real business use.
